# Projeto Back-end Raízes do Nordeste

API REST desenvolvida em Node.js para gerenciamento de pedidos da rede fictícia Raízes do Nordeste.

## Tecnologias
- Node.js
- Express
- SQLite
- Sequelize
- JWT
- Swagger

## Executar projeto

npm install
npm run dev

## Swagger
http://localhost:3000/api-docs
