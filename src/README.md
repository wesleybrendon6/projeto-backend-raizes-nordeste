# API Raízes do Nordeste

Projeto Back-end desenvolvido para o Projeto Multidisciplinar do curso de Análise e Desenvolvimento de Sistemas — UNINTER.

---

# Objetivo

Desenvolver uma API REST para gerenciamento operacional da rede fictícia “Raízes do Nordeste”, permitindo autenticação de usuários, gerenciamento de pedidos, controle operacional e integração simulada de pagamento.

---

# Tecnologias Utilizadas

- Node.js
- Express
- SQLite
- Sequelize
- JWT
- Swagger/OpenAPI
- Postman

---

# Funcionalidades

- Cadastro de usuários
- Login com JWT
- Rotas protegidas
- Criação de pedidos
- Controle de estoque
- Multicanalidade
- Atualização de status
- Pagamento mock
- Listagem de pedidos
- Documentação Swagger

---

# Arquitetura

O projeto foi desenvolvido utilizando arquitetura em camadas:

- API
- Application
- Domain
- Infrastructure
